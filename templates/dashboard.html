Quick start
  1. Download the demo CSV to preview working example data, or use the blank template.
  2. Keep the header row. Fill in one transaction per row and save as CSV UTF-8.
  3. Select the CSV and click Import CSV. The dashboard refreshes after a successful import.

Required columns: date (YYYY-MM-DD), customer, product, quantity, unit_price, revenue, and profit.

Optional columns: category, region, segment, and status.

Demo rows are fictional examples. Importing the same CSV again adds those transactions again—do not re-import unless you want duplicate demo sales in your totals. Limit: 5 MB / 5,000 rows.
